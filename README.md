# Modpack — L’Héritage de Poudlard

Dépôt de distribution du **modpack officiel de L’Héritage de Poudlard**.

Il contient les fichiers utilisés par le launcher pour maintenir l’environnement Minecraft des joueurs à jour.

> L’installation et les mises à jour sont normalement gérées automatiquement par **L’Héritage Launcher**.
